# AI应用与智能体开发
获课：shanxueit.com/14452/AI应用与智能体开发


百战程序员 - AI 应用与智能体开发：业务助手、文档智能体、多角色协同项目综合实训

企业落地 AI，往往从业务助手和文档智能体开始，但真正产生价值需要多角色协同和流程闭环。百战程序员 AI 应用与智能体开发课程围绕业务助手、文档智能体和多角色协同项目展开综合实训，帮助学员掌握智能体应用的系统化开发方法。

课程先讲 AI 应用的基本架构：模型接入、提示词管理、知识库、工具调用、会话管理和评测体系。业务助手方向强调任务理解、信息查询、流程引导和结果反馈。学员需要设计助手能做什么、不能做什么，以及遇到不确定问题时如何转人工。文档智能体方向覆盖文档解析、切分、索引、检索、摘要、问答和引用，重点解决知识更新、权限隔离和答案可追溯问题。多角色协同方向则让多个智能体分别承担不同职责，例如检索、审核、生成和质检，通过工作流完成复杂任务。

项目实训要求学员从业务场景出发，完成需求拆解、知识库建设、智能体角色设计、工作流编排和效果评测。课程会设置知识冲突、检索不准、工具失败、权限越权等异常场景，训练学员设计兜底和审计机制。学员还需要制定评测指标，结合人工评审和用户反馈持续优化。课程强调可运营性：没有评测和反馈的智能体，很难在业务中长期使用。

完成课程后，学员能够独立设计并实现业务助手、文档智能体和多角色协同应用，理解智能体开发中的工程约束和运营方法。课程适合 AI 应用开发者、产品经理、企业数字化项目成员和希望转型智能体开发的技术人员。课程以项目综合实训为核心，帮助学员把单点 AI 能力组合成可交付的业务方案。
